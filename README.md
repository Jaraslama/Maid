# Cleanup App

Malý nástroj pro Windows, který čistí běžná umístění se zbytečnými a dočasnými soubory. Po dokončení zobrazí oznámení s přehledem výsledků.

## Co čistí

- `C:\Windows\Logs\`
- `C:\Windows\Temp\`
- Dočasnou složku uživatele (`%TEMP%`)

Soubory a složky, které jsou uzamčené nebo je používá jiný program, se automaticky přeskočí. Souhrn vás informuje o tom, kolik položek nebylo možné odstranit.

## Požadavky

- Windows 10/11

## Stažení

Nejnovější verzi najdete na stránce [Releases](../../releases). K dispozici jsou dvě varianty:

> **Poznámka:** Čištění složek `C:\Windows\Logs\` a `C:\Windows\Temp\` může vyžadovat spuštění aplikace jako správce, protože se jedná o systémové složky.

## Upozornění

Tento nástroj soubory trvale odstraňuje. Používáte jej na vlastní riziko.
