# Maiden

## Co Maiden dělá

**Maiden je jednoduchý nástroj pro automatický úklid počítače.**

Windows a různé programy během používání vytvářejí dočasné soubory a další nepotřebná data. Maiden se je pokusí odstranit, aby udržel váš počítač čistší a uvolnil místo na disku.

### Automatický úklid

Při instalaci Maiden nastaví automatický úklid, který se spustí **při každém přihlášení do Windows**.

Nemusíte Maiden pokaždé ručně spouštět. Úklid proběhne automaticky na pozadí a po dokončení vám Windows zobrazí oznámení s výsledkem.

Maiden může pro provedení úklidu používat **oprávnění správce**, aby mohl vyčistit i systémové dočasné soubory.

### Jak Maiden odinstalovat

Pokud už Maiden nechcete používat, můžete ho jednoduše **odinstalovat v Nastavení Windows**.

Nastavení otevřete tlačítkem níže:

\<a href="ms-settings\:appsfeatures">Odinstalovat Maiden v Nastavení\</a>

> **Důležité:** Maiden trvale odstraňuje soubory. Používejte ho pouze v případě, že rozumíte tomu, že odstraněné soubory nemusí být možné obnovit.
